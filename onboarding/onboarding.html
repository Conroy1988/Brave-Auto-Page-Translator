When translation may run

03

Translation provider

Automatic mode uses the browser's on-device engine first. External services are used only after you configure and explicitly approve them.

Privacy checkpoint

When an external provider is used, readable webpage text—or writing you explicitly ask Smart Compose to translate—is sent over HTTPS to that provider. The Privacy Firewall masks common emails, phone numbers, URLs, references, dates and financial values first. Smart Compose excludes login, password, passcode, PIN, one-time-code, security-code and payment fields. The extension does not send cookies, full HTML, images or files. The developer does not receive text and the extension contains no analytics or advertising.
